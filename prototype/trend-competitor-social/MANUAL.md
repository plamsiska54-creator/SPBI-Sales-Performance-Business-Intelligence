# คู่มือการใช้งาน Trend & Competitor Analysis Dashboard

---

## 1. โปรแกรมนี้ช่วยอะไรคุณ

**Trend & Competitor Analysis Dashboard** คือแดชบอร์ดสำหรับดูข้อมูลเทรนด์สินค้า วิเคราะห์คู่แข่ง และติดตามกระแสบนสื่อสังคมออนไลน์ ทั้งหมดรวมอยู่ในหน้าเว็บเดียว

แดชบอร์ดนี้เหมาะสำหรับ:
- ทีมขาย ที่อยากรู้ว่าสินค้าไหนกำลังเป็นเทรนด์
- ทีมการตลาด ที่ต้องการเปรียบเทียบแบรนด์เรากับคู่แข่ง
- ทีมวางแผน ที่ต้องการติดตามว่าคนพูดถึงแบรนด์อย่างไรบนโซเชียลมีเดีย

> **หมายเหตุ:** ปัจจุบันแดชบอร์ดนี้เป็น **ต้นแบบ (Prototype)** ใช้ข้อมูลจำลองเพื่อการทดสอบ ยังไม่ได้เชื่อมต่อข้อมูลจริง

## 2. เริ่มต้นใช้งาน

### สิ่งที่ต้องเตรียม

คุณต้องมีโปรแกรม **Node.js** ติดตั้งอยู่ในเครื่อง หากยังไม่มี ให้ดาวน์โหลดจาก https://nodejs.org แล้วติดตั้งตามขั้นตอนบนหน้าเว็บ (กดปุ่ม Next ไปเรื่อย ๆ จนเสร็จ)

### วิธีเปิดโปรแกรม

**ขั้นตอนที่ 1** -- เปิดโปรแกรม **PowerShell** หรือ **Command Prompt**
- กดปุ่ม Windows บนคีย์บอร์ด แล้วพิมพ์คำว่า `PowerShell` จากนั้นกด Enter

**ขั้นตอนที่ 2** -- เข้าไปยังโฟลเดอร์ของโปรแกรม
- พิมพ์คำสั่งนี้แล้วกด Enter:
```
cd "C:\Users\Wanwa\OneDrive\Desktop\Project Sales\prototype\trend-competitor-social"
```

**ขั้นตอนที่ 3** -- เริ่มต้นเซิร์ฟเวอร์ (ตัวให้บริการเว็บ)
- พิมพ์คำสั่งนี้แล้วกด Enter:
```
npm start
```
- รอสักครู่ จะเห็นข้อความว่า `Trend Dashboard server running on http://localhost:3500`
- ข้อความนี้แปลว่าโปรแกรมพร้อมใช้งานแล้ว

**ขั้นตอนที่ 4** -- เปิดแดชบอร์ดในเว็บเบราว์เซอร์
- เปิด **Google Chrome** หรือ **Microsoft Edge**
- พิมพ์ในช่อง URL (แถบที่อยู่ด้านบน) ว่า:
```
http://localhost:3500
```
- กด Enter แล้วจะเห็นหน้าแดชบอร์ดปรากฏขึ้น

### วิธีปิดโปรแกรม

- กลับไปที่หน้าต่าง PowerShell ที่เปิดค้างอยู่
- กดปุ่ม `Ctrl + C` บนคีย์บอร์ดพร้อมกัน
- โปรแกรมจะหยุดทำงาน

## 3. ภาพรวมหน้าจอ

เมื่อเปิดแดชบอร์ดขึ้นมา จะเห็นส่วนต่าง ๆ เรียงจากบนลงล่างดังนี้:

### 3.1 แถบเตือนด้านบนสุด (สีเหลือง)

แถบสีเหลืองที่เขียนว่า "ข้อมูลจำลอง (Demo Data) เพื่อการทดสอบ" เป็นการแจ้งให้ทราบว่าข้อมูลที่แสดงเป็นข้อมูลตัวอย่าง ไม่ใช่ข้อมูลจริง แถบนี้จะติดอยู่ด้านบนตลอดเวลา

### 3.2 ส่วนหัว (Header)

แสดงชื่อ **Trend & Competitor Analysis** เป็นตัวหนังสือสีฟ้า-ม่วงไล่สี ถัดไปทางขวาจะมีข้อความ "Product Trends / Competitor Analysis / Social Listening" บอกว่าแดชบอร์ดนี้มีข้อมูล 3 ส่วน

### 3.3 แถบเลือกแท็บ (Tab Bar)

อยู่ใต้ส่วนหัว มีปุ่ม 3 ปุ่มเรียงกัน:
- **Product Trends** -- ดูเทรนด์สินค้ายอดนิยม
- **Competitor Analysis** -- เปรียบเทียบข้อมูลคู่แข่ง
- **Social Listening** -- ดูกระแสบนสื่อสังคมออนไลน์

ปุ่มที่กำลังเปิดอยู่จะเป็นสีฟ้า มีเส้นสีฟ้า-ม่วงที่ขอบล่าง กดปุ่มไหนก็จะสลับไปดูข้อมูลส่วนนั้น

### 3.4 การ์ดสรุปภาพรวม (Overview Cards)

อยู่ใต้แถบแท็บ มีกล่องสรุป 3 ใบเรียงกัน (บนหน้าจอกว้าง) แสดงตัวเลขสำคัญที่เปลี่ยนตามแท็บที่กำลังดู เมื่อนำเมาส์ไปชี้ที่การ์ด การ์ดจะยกขึ้นเล็กน้อย

### 3.5 แถบตัวกรอง (Filter Bar)

อยู่ใต้การ์ดสรุป มีช่องกรองข้อมูล 2 ช่อง:
- **ช่วงเวลา** -- เลือกว่าจะดูข้อมูลย้อนหลังกี่สัปดาห์
- **แพลตฟอร์ม** -- เลือกว่าจะดูข้อมูลจากแพลตฟอร์มไหน

(รายละเอียดการใช้งานอยู่ในหัวข้อที่ 7)

### 3.6 พื้นที่กราฟและตาราง

อยู่ใต้แถบตัวกรอง แสดงกราฟและตารางต่าง ๆ ตามแท็บที่เลือก กราฟทั้งหมดอยู่ในกรอบสี่เหลี่ยมที่มีพื้นหลังโปร่งแสงเล็กน้อย เมื่อนำเมาส์ไปชี้ที่กราฟ ขอบกรอบจะเปลี่ยนเป็นสีม่วง

## 4. แท็บ Product Trends (เทรนด์สินค้า)

แท็บนี้แสดงข้อมูลเกี่ยวกับสินค้าที่กำลังเป็นเทรนด์ในตลาด ยอดค้นหา และคีย์เวิร์ดที่คนนิยมค้นหา

### วิธีเปิดดู
- กดปุ่ม **Product Trends** ที่แถบแท็บด้านบน (เป็นปุ่มแรกทางซ้าย)
- โปรแกรมจะแสดงวงกลมหมุน (loading) สักครู่ แล้วแสดงข้อมูล

### การ์ดสรุป 3 ใบ

เมื่ออยู่ในแท็บนี้ การ์ดสรุปด้านบนจะแสดง:
- **การ์ดซ้าย - สินค้า Trending:** จำนวนสินค้าที่มีแนวโน้มขาขึ้น จากจำนวนสินค้าทั้งหมดที่ติดตาม
- **การ์ดกลาง - Top Category:** หมวดหมู่สินค้าที่มียอดค้นหาสูงสุด พร้อมตัวเลข Volume รวม
- **การ์ดขวา - Keywords:** จำนวนคีย์เวิร์ดทั้งหมดที่ติดตาม และจำนวนที่กำลังขาขึ้น

### กราฟที่ 1: Top 5 สินค้ายอดนิยม (มุมซ้ายบน)

- **ลักษณะ:** กราฟเส้น (Line Chart) แสดงยอดค้นหา (Search Volume) รายสัปดาห์
- **สิ่งที่เห็น:** เส้น 5 เส้น แต่ละเส้นเป็นสีต่างกัน แทนสินค้า 5 อันดับแรก (เรียงตามคะแนนสูงสุด)
- **แกนนอน:** ชื่อสัปดาห์ (W01, W02, ... W26)
- **แกนตั้ง:** ยอดค้นหา (แสดงเป็น K คือหลักพัน เช่น 15K = 15,000)
- **วิธีดูรายละเอียด:** นำเมาส์ไปชี้ที่จุดบนกราฟ จะขึ้นกล่องข้อความ (tooltip) แสดงชื่อสินค้าและยอดค้นหาของสัปดาห์นั้น
- **ชื่อสินค้าแต่ละเส้น:** ดูได้จากคำอธิบายสี (legend) ที่ด้านบนของกราฟ

**ตัวอย่าง:** ถ้าอยากรู้ว่าสินค้า "สาหร่ายทอดกรอบ" มียอดค้นหาเท่าไรในสัปดาห์ที่ 10 ให้เลื่อนเมาส์ไปที่จุดบนเส้นสีที่ตรงกับสินค้านั้น ตรงตำแหน่ง W10 กล่องข้อความจะแสดงตัวเลขขึ้นมา

### กราฟที่ 2: เทรนด์ตามหมวดหมู่ (มุมขวาบน)

- **ลักษณะ:** กราฟแท่งนอน (Horizontal Bar Chart) แสดงปริมาณการค้นหารวมของแต่ละหมวดสินค้า
- **สิ่งที่เห็น:** แท่งสีต่าง ๆ เรียงตามหมวดหมู่ เช่น ขนมกรอบ/ทอด, ขนมอบ, ขนมเพื่อสุขภาพ, ขนมนำเข้า, ขนมท้องถิ่น, เครื่องดื่ม/ของเหลว
- **แท่งยิ่งยาว = ยอดค้นหายิ่งมาก**
- **วิธีดูรายละเอียด:** นำเมาส์ไปชี้ที่แท่ง จะขึ้นตัวเลข Volume

**ตัวอย่าง:** ถ้าอยากเปรียบเทียบว่าหมวด "ขนมกรอบ/ทอด" กับ "ขนมเพื่อสุขภาพ" หมวดไหนมียอดค้นหามากกว่า ให้ดูว่าแท่งไหนยาวกว่า

### กราฟที่ 3: คีย์เวิร์ดยอดนิยม (กว้างเต็มหน้าจอ)

- **ลักษณะ:** กราฟแท่งนอน (Horizontal Bar Chart) แสดง Top 20 คีย์เวิร์ดที่คนค้นหามากที่สุด
- **สีของแท่งบอกแนวโน้ม:**
  - **สีเขียว** = คีย์เวิร์ดนี้กำลัง **ขาขึ้น** (มีคนค้นหาเพิ่มขึ้น)
  - **สีเหลือง** = คีย์เวิร์ดนี้ **ทรงตัว** (ยอดค้นหาคงที่)
  - **สีแดง** = คีย์เวิร์ดนี้ **ขาลง** (มีคนค้นหาลดลง)
- **ชื่อคีย์เวิร์ด:** แสดงทางด้านซ้ายของแท่ง ต่อท้ายด้วยสัญลักษณ์ [+] (ขาขึ้น), [=] (ทรงตัว), หรือ [-] (ขาลง)
- **วิธีดูรายละเอียด:** นำเมาส์ไปชี้ที่แท่ง จะแสดงยอดค้นหาพร้อมเปอร์เซ็นต์การเปลี่ยนแปลง

**ตัวอย่าง:** ถ้าเห็นแท่งสีเขียวยาว ๆ เขียนว่า "ขนมไทยออนไลน์ [+]" แปลว่าคำนี้มีคนค้นหาเยอะและกำลังเพิ่มขึ้น ซึ่งอาจเป็นโอกาสในการทำการตลาด

### ตารางสินค้ายอดนิยม (ด้านล่างสุด)

- แสดง 10 สินค้าอันดับแรก เรียงตามคะแนน
- คอลัมน์ในตาราง:
  - **#** -- ลำดับ
  - **สินค้า** -- ชื่อสินค้า
  - **แบรนด์** -- ยี่ห้อ
  - **หมวดหมู่** -- ประเภทสินค้า
  - **คะแนน** -- คะแนนความนิยม (ยิ่งสูงยิ่งฮิต)
  - **แนวโน้ม** -- ลูกศรสีเขียวชี้ขึ้น = ขาขึ้น, ลูกศรสีแดงชี้ลง = ขาลง, ลูกศรชี้ขวา = ทรงตัว

## 5. แท็บ Competitor Analysis (วิเคราะห์คู่แข่ง)

แท็บนี้แสดงข้อมูลเปรียบเทียบระหว่างแบรนด์ 6 แบรนด์ ได้แก่ วรรณวนัช, เถ้าแก่น้อย, มโนราห์, ฮานามิ, เลย์ และโคอิเกะยะ

### วิธีเปิดดู
- กดปุ่ม **Competitor Analysis** ที่แถบแท็บ (ปุ่มกลาง)

### การ์ดสรุป 3 ใบ

- **การ์ดซ้าย - จำนวนคู่แข่ง:** จำนวนแบรนด์ที่ติดตามอยู่
- **การ์ดกลาง - Market Leader:** แบรนด์ที่มีส่วนแบ่งตลาดสูงสุด พร้อมตัวเลข Market Share
- **การ์ดขวา - ราคาเฉลี่ยตลาด:** ราคาเฉลี่ยของทุกแบรนด์ (หน่วย: บาท)

### กราฟที่ 1: เปรียบเทียบราคาเฉลี่ย (มุมซ้ายบน)

- **ลักษณะ:** กราฟแท่งตั้ง (Bar Chart) แสดงราคาเฉลี่ยของแต่ละแบรนด์
- **แกนนอน:** ชื่อแบรนด์
- **แกนตั้ง:** ราคา (บาท)
- **แต่ละแบรนด์มีสีเฉพาะ** เช่น วรรณวนัช = ม่วง, เถ้าแก่น้อย = เขียว, มโนราห์ = แดง เป็นต้น
- **วิธีดูรายละเอียด:** ชี้เมาส์ที่แท่ง จะแสดงราคาเฉลี่ยเป็นบาท

**ตัวอย่าง:** ถ้าอยากรู้ว่าราคาของวรรณวนัชอยู่ตรงไหนเมื่อเทียบกับคู่แข่ง ให้ดูว่าแท่งสีม่วงสูงหรือต่ำกว่าแท่งอื่น

### กราฟที่ 2: คะแนนรีวิวเปรียบเทียบ (มุมขวาบน)

- **ลักษณะ:** กราฟเรดาร์ (Radar Chart) รูปใยแมงมุม แสดงคะแนนรีวิวใน 6 มิติ
- **6 มิติที่เปรียบเทียบ:**
  - **รสชาติ** -- ความอร่อย
  - **คุ้มค่า** -- ราคาเทียบกับปริมาณ
  - **บรรจุภัณฑ์** -- ความสวยงามและคุณภาพของหีบห่อ
  - **ความสด** -- ความสดใหม่ของสินค้า
  - **จัดส่ง** -- ความรวดเร็วและคุณภาพในการจัดส่ง
  - **ภาพรวม** -- คะแนนรวมทั้งหมด
- **คะแนนตั้งแต่ 0 ถึง 5** (จากศูนย์กลางออกไปถึงขอบ)
- **แต่ละแบรนด์เป็นเส้นสีต่างกัน** ดูคำอธิบายสีที่ด้านล่างของกราฟ
- **ยิ่งพื้นที่กว้าง = ยิ่งได้คะแนนดีรอบด้าน**

**ตัวอย่าง:** ถ้าเส้นของวรรณวนัช (สีม่วง) ยื่นออกไปไกลในมิติ "รสชาติ" แต่หดเข้ามาในมิติ "บรรจุภัณฑ์" แปลว่าลูกค้าให้คะแนนรสชาติสูงแต่บรรจุภัณฑ์ยังต้องปรับปรุง

### กราฟที่ 3: ยอดขายรายสัปดาห์ (กว้างเต็มหน้าจอ)

- **ลักษณะ:** กราฟเส้น (Line Chart) แสดงยอดขายรายสัปดาห์ของทั้ง 6 แบรนด์
- **แกนนอน:** สัปดาห์ (W01 ถึง W26)
- **แกนตั้ง:** ยอดขาย (แสดงเป็น M คือล้าน เช่น 1.5M = 1,500,000 บาท)
- **เส้น 6 เส้น** แยกสีตามแบรนด์ ดูคำอธิบายสีที่ด้านล่างของกราฟ
- **วิธีดูรายละเอียด:** นำเมาส์ไปชี้ที่จุดบนกราฟ จะแสดงยอดขายของทุกแบรนด์ในสัปดาห์นั้น

### กราฟที่ 4: ส่วนแบ่งตลาด (ด้านซ้ายล่าง)

- **ลักษณะ:** กราฟโดนัท (Doughnut Chart) แสดงสัดส่วนส่วนแบ่งตลาดของแต่ละแบรนด์
- **แต่ละชิ้นของโดนัท = 1 แบรนด์** สีตรงกับแบรนด์
- **ชิ้นที่ใหญ่กว่า = มีส่วนแบ่งตลาดมากกว่า**
- มีชิ้น "อื่น ๆ" (สีเทา) สำหรับส่วนแบ่งที่เหลือในตลาด
- **วิธีดูรายละเอียด:** ชี้เมาส์ที่ชิ้นส่วน จะแสดงเปอร์เซ็นต์ส่วนแบ่งตลาด
- ดูคำอธิบายสีและชื่อแบรนด์ที่ด้านล่างของกราฟ

### ตารางเปรียบเทียบคู่แข่ง (ด้านล่างสุด)

- แสดงรายละเอียดของทุกแบรนด์ในรูปแบบตาราง
- คอลัมน์ในตาราง:
  - **แบรนด์** -- ชื่อและไอคอน
  - **สินค้า** -- จำนวนสินค้าที่ขาย
  - **ราคาเฉลี่ย** -- ราคาเฉลี่ย (บาท)
  - **Rating** -- คะแนนรีวิวภาพรวม (จาก 5.0)
  - **รีวิว** -- จำนวนรีวิวทั้งหมด
  - **Market Share** -- ส่วนแบ่งตลาด (เปอร์เซ็นต์)
  - **กลยุทธ์** -- กลยุทธ์การตลาดหลักของแบรนด์

## 6. แท็บ Social Listening (ฟังเสียงจากโซเชียล)

แท็บนี้แสดงว่าคนพูดถึงแบรนด์และสินค้าอย่างไรบนสื่อสังคมออนไลน์ ครอบคลุม 5 แพลตฟอร์ม: Facebook, Instagram, X (Twitter), TikTok และ Pantip

### วิธีเปิดดู
- กดปุ่ม **Social Listening** ที่แถบแท็บ (ปุ่มขวาสุด)

### การ์ดสรุป 3 ใบ

- **การ์ดซ้าย - Total Mentions:** จำนวนครั้งที่ถูกพูดถึงทั้งหมด บอกด้วยว่ามาจากกี่แพลตฟอร์ม
- **การ์ดกลาง - Overall Sentiment:** เปอร์เซ็นต์ความรู้สึกเชิงบวก (Positive) จากข้อความทั้งหมด
- **การ์ดขวา - Top Hashtag:** แฮชแท็กที่ถูกใช้มากที่สุด พร้อมเปอร์เซ็นต์การเปลี่ยนแปลงและจำนวน mentions

### กราฟที่ 1: Mentions รายสัปดาห์ (กว้างเต็มหน้าจอ)

- **ลักษณะ:** กราฟเส้น (Line Chart) แสดงจำนวนครั้งที่ถูกพูดถึงบนแต่ละแพลตฟอร์ม รายสัปดาห์
- **เส้นแต่ละเส้น = 1 แพลตฟอร์ม** มีสีเฉพาะ:
  - Facebook = สีน้ำเงิน
  - Instagram = สีชมพู
  - X (Twitter) = สีฟ้า
  - TikTok = สีแดง
  - Pantip = สีม่วง
- **แกนนอน:** สัปดาห์ (W01 ถึง W26)
- **แกนตั้ง:** จำนวน mentions
- **วิธีดูรายละเอียด:** ชี้เมาส์ที่จุดใด ๆ บนกราฟ จะแสดงยอดของทุกแพลตฟอร์มในสัปดาห์นั้น

**ตัวอย่าง:** ถ้าเห็นเส้น TikTok (สีแดง) พุ่งขึ้นอย่างชัดเจนในสัปดาห์ที่ 5 อาจหมายความว่ามีคลิปที่เกี่ยวกับแบรนด์ถูกแชร์อย่างกว้างขวางในช่วงนั้น

### กราฟที่ 2: Sentiment Analysis (มุมซ้ายล่าง)

- **ลักษณะ:** กราฟโดนัท (Doughnut Chart) แสดงสัดส่วนความรู้สึกของข้อความที่พูดถึงแบรนด์
- **3 ส่วนของโดนัท:**
  - **สีเขียว (Positive)** -- ข้อความเชิงบวก เช่น ชม, ชอบ, แนะนำ
  - **สีเทา (Neutral)** -- ข้อความกลาง ๆ เช่น ถาม, แจ้งข้อมูล
  - **สีแดง (Negative)** -- ข้อความเชิงลบ เช่น ร้องเรียน, ไม่พอใจ
- **ตรงกลางวงโดนัท:** แสดงเปอร์เซ็นต์ Positive เป็นตัวเลขใหญ่
- ดูเปอร์เซ็นต์แต่ละส่วนได้จากคำอธิบายด้านล่างกราฟ

**ตัวอย่าง:** ถ้าเห็น Positive 65%, Neutral 25%, Negative 10% แปลว่าส่วนใหญ่คนพูดถึงแบรนด์ในเชิงบวก

### กราฟที่ 3: แพลตฟอร์ม (มุมขวาล่าง)

- **ลักษณะ:** กราฟแท่งตั้ง (Bar Chart) แสดงจำนวน mentions รวมของแต่ละแพลตฟอร์ม
- **แท่งยิ่งสูง = มีคนพูดถึงบนแพลตฟอร์มนั้นมากกว่า**
- **วิธีดูรายละเอียดเพิ่มเติม:** ชี้เมาส์ที่แท่ง จะแสดง:
  - จำนวน mentions ทั้งหมด
  - ค่าเฉลี่ย Engagement (ยอดไลค์/แชร์/คอมเมนต์)
  - ประเภทเนื้อหาที่ได้รับความนิยมสูงสุด (Top Content)

### กราฟที่ 4: Hashtags ยอดนิยม (กว้างเต็มหน้าจอ)

- **ลักษณะ:** กราฟแท่งนอน (Horizontal Bar Chart) แสดง Top 15 แฮชแท็กที่ถูกใช้มากที่สุด
- **สีของแท่งบอกแนวโน้ม:**
  - **สีเขียว** = แฮชแท็กนี้กำลัง **ขาขึ้น** (มีคนใช้เพิ่มขึ้น)
  - **สีเทา** = แฮชแท็กนี้ **ทรงตัว**
  - **สีแดง** = แฮชแท็กนี้ **ขาลง** (มีคนใช้ลดลง)
- **ชื่อแฮชแท็ก:** แสดงทางด้านซ้ายของแท่ง ต่อท้ายด้วยลูกศร (ลูกศรขึ้น = ขาขึ้น, ลูกศรลง = ขาลง, ลูกศรขวา = ทรงตัว)
- **วิธีดูรายละเอียด:** ชี้เมาส์ที่แท่ง จะแสดงจำนวน mentions พร้อมเปอร์เซ็นต์การเปลี่ยนแปลง

## 7. การใช้ตัวกรอง (Filters)

ทุกแท็บจะมีแถบตัวกรองที่ใช้กรองข้อมูลให้แคบลงได้ ตัวกรองมี 2 ชนิด:

### 7.1 ตัวกรองช่วงเวลา (ช่วงเวลา)

- กดที่ช่องถัดจากคำว่า "ช่วงเวลา" จะมีตัวเลือกขึ้นมา:
  - **ทั้งหมด (6 เดือน)** -- แสดงข้อมูลทั้ง 26 สัปดาห์ (ค่าเริ่มต้น)
  - **4 สัปดาห์ล่าสุด** -- แสดงเฉพาะข้อมูล 4 สัปดาห์ล่าสุด
  - **8 สัปดาห์ล่าสุด** -- แสดงเฉพาะข้อมูล 8 สัปดาห์ล่าสุด
  - **12 สัปดาห์ล่าสุด** -- แสดงเฉพาะข้อมูล 12 สัปดาห์ล่าสุด
- เลือกตัวเลือกที่ต้องการ กราฟจะอัปเดตทันทีโดยไม่ต้องกดปุ่มอื่นเพิ่มเติม

**ตัวอย่าง:** ถ้าต้องการดูเฉพาะข้อมูลเดือนล่าสุด ให้เลือก "4 สัปดาห์ล่าสุด" กราฟเส้นจะแสดงแค่ 4 จุดข้อมูลล่าสุด ทำให้เห็นรายละเอียดชัดขึ้น

### 7.2 ตัวกรองแพลตฟอร์ม (แพลตฟอร์ม)

- กดที่ช่องถัดจากคำว่า "แพลตฟอร์ม" จะมีตัวเลือกขึ้นมา:
  - **ทั้งหมด** -- แสดงข้อมูลจากทุกแพลตฟอร์ม (ค่าเริ่มต้น)
  - **Facebook, Instagram, X (Twitter), TikTok** -- แพลตฟอร์มโซเชียลมีเดีย
  - **Shopee, Lazada, Amazon** -- แพลตฟอร์มอีคอมเมิร์ซ (ร้านค้าออนไลน์)
  - **Pantip** -- เว็บบอร์ดไทย
- เลือกแพลตฟอร์มที่สนใจ กราฟจะกรองข้อมูลให้แสดงเฉพาะแพลตฟอร์มนั้น

**ตัวอย่าง:** ถ้าต้องการดูว่าบน TikTok มีคนพูดถึงแบรนด์อย่างไร ให้เลือก "TikTok" ที่ตัวกรองแพลตฟอร์ม

### 7.3 ตัวกรองคงค่าเมื่อสลับแท็บ

เมื่อเลือกตัวกรองแล้ว ค่าที่เลือกไว้จะ **คงอยู่** แม้จะสลับไปดูแท็บอื่น เช่น ถ้าเลือก "4 สัปดาห์ล่าสุด" ที่แท็บ Product Trends แล้วสลับไปแท็บ Competitor Analysis ตัวกรองจะยังคงเป็น "4 สัปดาห์ล่าสุด" ไม่ต้องเลือกใหม่

ถ้าต้องการกลับไปดูข้อมูลทั้งหมด ให้เปลี่ยนตัวกรองกลับเป็น "ทั้งหมด" ที่ช่องช่วงเวลา และ "ทั้งหมด" ที่ช่องแพลตฟอร์ม

## 8. คำถามที่พบบ่อย (FAQ)

**ถาม: ข้อมูลที่แสดงเป็นข้อมูลจริงหรือไม่?**
ตอบ: ไม่ใช่ ข้อมูลที่แสดงเป็นข้อมูลจำลอง (Demo Data) เพื่อทดสอบระบบ สังเกตได้จากแถบสีเหลืองด้านบนที่เขียนว่า "ข้อมูลจำลอง (Demo Data) เพื่อการทดสอบ" ข้อมูลครอบคลุมช่วงสัปดาห์ที่ 1-26 ของปี 2026

**ถาม: ต้องเชื่อมต่ออินเทอร์เน็ตหรือไม่?**
ตอบ: ไม่ต้อง แดชบอร์ดนี้ทำงานในเครื่องคอมพิวเตอร์ของคุณโดยไม่ต้องเชื่อมต่ออินเทอร์เน็ต ข้อมูลทั้งหมดอยู่ในไฟล์ที่เครื่อง

**ถาม: เปิดได้พร้อมกันหลายคนหรือไม่?**
ตอบ: แดชบอร์ดทำงานบนเครื่องของคุณเท่านั้น คนอื่นไม่สามารถเข้าถึงจากเครื่องอื่นได้ (ยกเว้นจะอยู่ในเครือข่ายเดียวกันและรู้ที่อยู่เครื่อง)

**ถาม: ทำไมต้องพิมพ์ npm start ทุกครั้ง?**
ตอบ: คำสั่ง `npm start` เป็นการเปิดตัวให้บริการเว็บ (server) ซึ่งต้องเปิดทิ้งไว้ตลอดเวลาที่ใช้งานแดชบอร์ด ถ้าปิดหน้าต่าง PowerShell ไป server จะหยุดทำงานและเปิดเว็บไม่ได้ ต้องพิมพ์ `npm start` ใหม่

**ถาม: สามารถส่งออก (export) กราฟเป็นรูปภาพได้หรือไม่?**
ตอบ: ปัจจุบันยังไม่มีฟีเจอร์ส่งออกกราฟ แต่สามารถใช้วิธีจับภาพหน้าจอ (Screenshot) ด้วยการกดปุ่ม `Print Screen` บนคีย์บอร์ด หรือใช้เครื่องมือ Snipping Tool ของ Windows

**ถาม: มีแบรนด์อะไรบ้างในข้อมูลคู่แข่ง?**
ตอบ: มี 6 แบรนด์ ได้แก่ วรรณวนัช, เถ้าแก่น้อย, มโนราห์, ฮานามิ, เลย์ และโคอิเกะยะ

**ถาม: เปิดบนมือถือได้ไหม?**
ตอบ: แดชบอร์ดออกแบบสำหรับใช้งานบนคอมพิวเตอร์และแท็บเล็ต (หน้าจอกว้างตั้งแต่ 768 พิกเซลขึ้นไป) การใช้งานบนมือถืออาจแสดงผลไม่สมบูรณ์

## 9. ปัญหาที่อาจเจอ และ วิธีแก้

### ปัญหา: พิมพ์ npm start แล้วขึ้นข้อความ "npm is not recognized"

**สาเหตุ:** ยังไม่ได้ติดตั้ง Node.js หรือติดตั้งแล้วแต่ยังไม่ได้รีสตาร์ทเครื่อง
**วิธีแก้:**
1. ดาวน์โหลด Node.js จาก https://nodejs.org แล้วติดตั้ง
2. ปิดหน้าต่าง PowerShell แล้วเปิดใหม่
3. ลองพิมพ์ `npm start` อีกครั้ง

### ปัญหา: เปิดเว็บแล้วขึ้น "ไม่สามารถเข้าถึงไซต์นี้" หรือ "This site can't be reached"

**สาเหตุ:** ยังไม่ได้เปิด server หรือ server หยุดทำงาน
**วิธีแก้:**
1. ตรวจดูว่าหน้าต่าง PowerShell ที่พิมพ์ `npm start` ยังเปิดอยู่หรือไม่
2. ถ้าปิดไปแล้ว ให้เปิด PowerShell ขึ้นมาใหม่ เข้าโฟลเดอร์โปรแกรม แล้วพิมพ์ `npm start`
3. รอจนเห็นข้อความ "Trend Dashboard server running on http://localhost:3500"
4. ลอง refresh เว็บเบราว์เซอร์ (กดปุ่ม F5)

### ปัญหา: เปิดเว็บแล้วเห็นแต่หน้าขาวว่าง ๆ หรือขึ้นข้อความ "เกิดข้อผิดพลาดในการโหลดข้อมูล"

**สาเหตุ:** ไฟล์ข้อมูล (JSON) อาจถูกลบ ย้าย หรือเสียหาย
**วิธีแก้:**
1. ตรวจดูว่ามีไฟล์ 3 ไฟล์ในโฟลเดอร์ `public\data\` ได้แก่ `trends.json`, `competitors.json` และ `social.json`
2. ถ้าไฟล์หาย ให้คัดลอกจากแหล่งสำรอง หรือแจ้งทีมพัฒนา
3. ลอง refresh เว็บเบราว์เซอร์ (กดปุ่ม F5)

### ปัญหา: กราฟแสดงว่า "ไม่พบข้อมูลในเงื่อนไขที่เลือก"

**สาเหตุ:** ตัวกรอง (filter) ที่เลือกอาจไม่มีข้อมูลตรงตามเงื่อนไข
**วิธีแก้:**
1. ลองเปลี่ยนตัวกรอง "ช่วงเวลา" เป็น "ทั้งหมด (6 เดือน)"
2. เปลี่ยนตัวกรอง "แพลตฟอร์ม" เป็น "ทั้งหมด"
3. กราฟจะแสดงข้อมูลทั้งหมดกลับมา

### ปัญหา: กราฟซ้อนกัน หรือแสดงผลแปลก ๆ เมื่อสลับแท็บ

**สาเหตุ:** อาจเกิดขึ้นได้น้อยมากเมื่อกดสลับแท็บเร็วมาก ๆ
**วิธีแก้:**
1. กดปุ่ม F5 เพื่อรีเฟรช (โหลดหน้าเว็บใหม่)
2. ปัญหาจะหายไป

### ปัญหา: ตัวหนังสือภาษาไทยแสดงเป็นสัญลักษณ์แปลก ๆ

**สาเหตุ:** การตั้งค่าภาษาของเว็บเบราว์เซอร์อาจไม่ถูกต้อง
**วิธีแก้:**
1. ลองเปิดเว็บด้วย Google Chrome หรือ Microsoft Edge เวอร์ชันล่าสุด
2. ถ้ายังมีปัญหา ให้แจ้งทีมพัฒนา
